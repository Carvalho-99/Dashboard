Instalando a atualização

Da versão {{ versao_atual }} para a versão {{ versao_nova }}

  • O programa baixa a versão nova, fecha e abre de novo sozinho.
  • Suas contas, rendas e pagamentos continuam onde estão.
  • Antes da troca é guardada uma cópia do banco de dados na mesma pasta, com o nome financas.db.bak-{{ versao_atual }}.
  • Se a versão nova não abrir, a anterior volta sozinha.

Não desligue o computador agora. Esta página vai parar de responder em alguns segundos — é o programa encerrando para trocar os arquivos. É normal.

Em até cinco minutos o Organizador Financeiro abre de novo por conta própria. Se não abrir, abra pelo atalho de sempre: seus dados estão intactos e a versão anterior continua funcionando.

Se o programa voltar na versão {{ versao_atual }}, a atualização não foi aplicada — nada foi perdido. O motivo fica escrito no arquivo atualizacao.log, na mesma pasta do programa: é esse arquivo que o suporte vai pedir.
